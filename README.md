
# Montgomery County Traffic Crash Analysis

## About This Project

I'm analyzing public traffic crash data from Montgomery County, Maryland, to better understand patterns in when and where crashes occur.

This is my first independent data analytics project. My goal is to build experience with Python, SQL, data cleaning, and data visualization while working with a real-world dataset.

## Questions I Want to Explore

- Which days of the week have the most reported crashes?
- What times of day have the highest crash counts?
- How do crash patterns vary by location?
- What can the data tell us about crash severity?
